rpning 0.2.1 - Installation and first run
Repository: https://github.com/Nemeth-Tamas/rpning
Releases: https://github.com/Nemeth-Tamas/rpning/releases

RUN A PREBUILT BINARY
Download the binary matching your operating system and architecture from the
v0.2.1 release. Rust is not needed to run a prebuilt binary. SHA256SUMS.txt
contains SHA-256 checksums.

Windows x64:
  Download rpn-Windows-X64.exe and optionally rename it rpn.exe.
  Open PowerShell in that directory and run:
    .\rpn.exe
    .\rpn.exe --keypad
    .\rpn.exe --eval "0.1 0.2 +"

Linux x64 / macOS ARM64:
  Download the matching Linux-X64 or macOS-ARM64 binary and rename it rpn.
  Run:
    chmod +x ./rpn
    ./rpn
    ./rpn --eval "0.1 0.2 +"
  Dedicated keypad input and advanced line editing currently require Windows.
  The ordinary REPL, pipes, scripts and macro engine work on all three systems.

BUILD OR UPDATE FROM SOURCE
Install a current stable Rust toolchain. From the repository root:
  git pull --ff-only
  cargo build --release --locked

Windows executable:
  .\target\release\rpn.exe
  .\target\release\rpn.exe --repl
  .\target\release\rpn.exe --tui
  .\target\release\rpn.exe --keypad
  .\target\release\rpn.exe --keypad-diagnose
  .\target\release\rpn.exe --run examples/invoice.rpn

Version 0.2.1 starts the TUI by default on a Windows terminal. F5 switches
NUM/CMD input; F2 toggles Base/Alt; F3 changes focus; F4 switches stack/history;
F6 browses complete command/help output. --repl keeps the ordinary line editor.
Pipes and redirected output use plain line input. The v0.2.1 binaries include
the TUI, extended math and embedded guides. Older v0.1.0 binaries predate them.
In CMD, :display without an argument shows current/allowed values; Tab offers
setting-argument completion. :help tui and :help program open embedded guides.
Full references: docs/TUI.md (including all layers) and docs/PROGRAM_GUIDE.md
(all program features, including advanced macros, scripts and mathematics).

KEYPAD FIRST CALCULATION
With numeric input enabled on the numpad:
  12, Enter, 3, +, 2, *
The result is 30; arithmetic operators execute immediately.
Navigation-mode keys use configurable nav shortcuts. F2 toggles base/alt.
Use :bindings in the ordinary REPL to inspect mappings.

PROGRAMMING
  : square "Square X" dup * ;
  5 square
  :bind nav home square
  :settings-save

See :help, README.md, docs/LANGUAGE.md, docs/WORKFLOW.md and docs/KEYPAD.md.
Interactive sessions save macros/settings automatically and history on exit.
Registers persist only on explicit :save/:load. State is normally stored in
%APPDATA%/rpning on Windows; set RPNING_HOME to choose another directory.
Pipes, --eval and --run start fresh rather than implicitly loading user state.

DEVELOPER VALIDATION
  cargo fmt --check
  cargo check --locked
  cargo test --locked
  cargo clippy --locked --all-targets --all-features -- -D warnings
  python tools/precision_oracle.py target/release/rpn.exe
  python tools/transcendental_oracle.py target/release/rpn.exe
  python tools/keypad_console_smoke.py target/release/rpn.exe
Use target/release/rpn without .exe on Linux/macOS; the console smoke test is
Windows-only. GitHub Actions runs cross-platform checks and release builds.

The old tools/apply_* and tools/install_* scripts are historical slice helpers.
Do not run them over the current release; update via Git instead.
